# AI Defense Matrix

The AI Defense Matrix is a framework for defending AI systems, by Lenny Zeltser and Sounil Yu. It aligns with NIST CSF 2.0 and extends the Cyber Defense Matrix.

Read the framework at **[aidefensematrix.com](https://aidefensematrix.com)**.

The [catalog data](https://github.com/aidefensematrix/aidefensematrix-catalog-data) lists products that secure AI and maps each to the matrix. Open a pull request there to suggest a product or a fix.
