# AI Defense Matrix

The [AI Defense Matrix](https://aidefensematrix.com) is a framework for defending AI systems, by Lenny Zeltser and Sounil Yu. It aligns with NIST CSF 2.0 and extends the [Cyber Defense Matrix](https://cyberdefensematrix.com/).

The [catalog data](https://github.com/aidefensematrix/aidefensematrix-catalog-data) lists products that secure AI and maps each to the matrix. It's used as the basis for the [AI Defense Matrix Catalog](https://catalog.aidefensematrix.com).
